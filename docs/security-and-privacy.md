# Security, Privacy & Sanitization Policy

## 1. Company Neutrality & Privacy Safeguards
- **100% Synthetic Data:** All teacher identities, student workbook samples, school emblems, and customer telephone numbers are synthetic mocks created specifically for public portfolio demonstration.
- **Brand Excise:** Real commercial client trademarks, original logos, and founder backstories have been thoroughly removed and replaced by the neutral **Etqan EduPlatform** identity.
- **Zero Exposed Cloud Secrets:** No active API keys, Supabase service keys, or cloud database credentials exist in this repository.

## 2. Protected Asset Distribution
- **Protected PDF Viewer:** Client-side event filters intercept `Ctrl+S`, `Ctrl+P`, and mouse right-click events to prevent unauthorized downloading or inspection of proprietary printable templates.
- **Quarantined Secrets:** `.gitignore` explicitly blocks all `.env` variants while `.env.example` provides a sanitized configuration template.
